# LATCH project page

Zero-dependency static HTML/CSS/JavaScript. No framework, external font, analytics, backend, or runtime secret. The project protocol itself is in `../latch.mjs`; the website is only its documentation and interactive recorded trace.

## Preview

```sh
npm run dev -- --host 127.0.0.1 --port 7100
```

`--host=...` and `--port=...` are supported too. The development server is for local preview only and is not part of the deployable static site.

## Build

```sh
npm run build
```

This creates `dist/` containing `index.html` and `src/`. No bundler or package installation is needed.

- `src/trace.js` is generated from an actual `node ../latch.mjs demo --trace ../examples/trace.json` exchange. The provider is simulated.
- `src/metrics.js` is generated by `npm run bench` in the repository root. It reports local measurements, not cross-protocol rankings.
- RU/EN is selectable and persists in this browser's localStorage only.
- Trace playback, message switching, copying, and keyboard navigation are functional. Reduced-motion preferences disable playback; the play control then advances one discrete step.
- Stars and forks use the public GitHub repository API. Loading and API failures display an explicit unavailable state, never invented values.

For an automated real-browser release check, run `node test/browser-check.mjs` from the repository root. It launches a temporary local Chrome/Chromium/Edge (override detection with `CHROME_BIN`), verifies exact 375/768/1024/1440px viewports, RU/EN, live and failed GitHub API states, playback, actual keyboard events, all four clipboard controls, console errors, and HTTP failures. Temporary browser and preview processes are stopped in `finally`; temporary screenshots and the report are in `.test-tmp/browser-check/`. To run the same checks against a deployed static page without starting a local server, set `LATCH_TEST_ORIGIN`, for example `LATCH_TEST_ORIGIN=https://latch.kimi.page node test/browser-check.mjs`.

The source page has no external asset dependencies. The Kimi.page host normalizes HTML and injects its own `sdk-seed.js` with `data-kimi-analytics="false"`; that host addition is not part of the repository bundle.

Before delivery, check 375/768/1024/1440px layouts, all visible controls, keyboard focus, console errors, and failed resource requests.
